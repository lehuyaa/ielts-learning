# UI Review Checklist

Use this checklist before marking any frontend UI task complete.

- Consistent spacing.
- Consistent typography hierarchy.
- Consistent card padding.
- Header to content spacing >= 48px.
- Label to input spacing = 8px.
- Input group spacing = 24px.
- Form field to primary button spacing = 32px.
- Responsive desktop and mobile layout.
- No visual crowding.
- No arbitrary one-off spacing values.
